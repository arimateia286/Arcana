# Arcana

**Arcana** é um projeto de Tarot Online simples e rápido, com interface minimalista e foco em consultas diretas que construí junto com minha namorada, que estava estudando sobre tarô. O projeto serviu como uma grande aprendizagem para mim, ajudando na fixação de meus conhecimentos em HTML, CSS e JavaScript. O objetivo é proporcionar uma experiência leve e sem distrações para quem deseja realizar uma leitura de tarot.

## 🌟 Funcionalidades

- 🃏 Tiragem de cartas de Tarot de forma aleatória.
- 📱 Layout responsivo para celular, tablet e desktop.
- 🎨 Interface inspirada em design clean, com ênfase nas cartas.
- 🌐 Aplicação 100% web, não precisa instalar nada.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (puro, sem frameworks)

## 💡 Ideia por trás do projeto

A proposta do **Arcana** é ser uma alternativa minimalista aos sites de tarot tradicionais. Sem propagandas, sem formulários, apenas a experiência da leitura.
